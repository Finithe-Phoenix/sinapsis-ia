Herramienta del anfitrión

Editor y cifrado del banco de preguntas

Cómo funciona

  1. Abre tu banco: carga privado/banco.json o descifra el data/banco.enc.json actual con su clave.
  2. Edita el JSON (preguntas, opciones, correct = 0 para A, 1 para B, 2 para C, 3 para D).
  3. Escribe una clave y descarga banco.enc.json. Reemplaza el archivo en la carpeta data/.

Todo ocurre en tu navegador: nada se envía a ningún servidor.
